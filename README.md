Python, Pandas & NumPy Practice

This repository contains solutions to questions that I solve while preparing for data science. It covers Python basics along with data manipulation using Pandas and numerical computing using NumPy. Each file includes the problem statement, topic, difficulty, and a clean solution.

Topics Covered
Python: strings, lists, dictionaries, loops, functions
NumPy: arrays, indexing, broadcasting, mathematical operations
Pandas: DataFrames, filtering, grouping, merging, handling missing values
